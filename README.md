# ITER / VS — Portfolio Prototype

Prototype static portfolio for Vashish Sookul.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload all files/folders in this directory.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`.
5. Choose `main` and `/root`.
6. Save.

## Replace placeholders
The large letter blocks in the case studies are visual placeholders.
Replace them later with real project images/videos while keeping the layout.

## Main files
- `index.html` — homepage
- `style.css` — all visual styling
- `script.js` — cursor and reveal animation
- `projects/*.html` — case studies
